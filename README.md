# MP3 to M4B

Joins mp3 parts into one .m4b audiobook with chapters and cover.

## Install

Terminal agents:

```sh
npx skills add geragarazagh/mp3-to-m4b -g
```

Claude Code:

```sh
claude plugin marketplace add geragarazagh/mp3-to-m4b
claude plugin install mp3-to-m4b@mp3-to-m4b
```

Gemini CLI:

```sh
gemini extensions install https://github.com/geragarazagh/mp3-to-m4b
```

Any other agent: paste the text of [`SKILL.md`](skills/mp3-to-m4b/SKILL.md) into its instructions.
